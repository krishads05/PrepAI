The critical section problem is to design a protocol so that no two processes execute in their critical sections at the same time. A solution must satisfy mutual exclusion, progress and bounded waiting.
A semaphore is an integer variable accessed only through two atomic operations, wait and signal. A binary semaphore can be used as a mutex lock to enforce mutual exclusion, while a counting semaphore controls access to a resource with multiple instances.
In the Dining Philosophers problem, five philosophers sit at a round table with one chopstick between each pair, and a philosopher needs both adjacent chopsticks to eat. Each chopstick is represented by a semaphore; a philosopher executes wait on the left and right chopstick semaphores before eating and signal on both after eating.
If every philosopher picks up the left chopstick at the same time, all of them wait forever, so the simple semaphore solution can cause deadlock. Deadlock can be avoided by allowing at most four philosophers at the table, by picking up both chopsticks only if both are available, or by an asymmetric solution where odd philosophers pick up the left chopstick first and even philosophers pick up the right chopstick first.
In the Producer-Consumer problem with a bounded buffer, the semaphore mutex provides mutual exclusion, the semaphore empty counts empty slots and the semaphore full counts filled slots.
In the Readers-Writers problem, multiple readers may read the shared data at the same time, but a writer needs exclusive access; the first readers-writers problem can cause writer starvation.
